# Workflow

Begin with brand position, emotional goal, reference images, usage rights and output medium. Produce a visual bible: palette, silhouette, material, lens, lighting, staging, motion, soundtrack and shot durations. Use restrained cuts when suitable. For 3D require actual geometry, rigging, shaders, lighting and render passes rather than labeling image-to-video as 3D. Validate face anatomy, realistic skin response, garment physics, continuity and export resolution. Distinguish generated imagery from documentary photography and request permission for protected materials.

# Deliverable checklist
- Record inputs and assumptions.
- Produce a draft and inspect it against the user brief.
- Report tests actually run, unresolved risks and next actions.
- Never claim installation, deployment, validation or access that did not occur.
