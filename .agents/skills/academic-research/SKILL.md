# Workflow

Define question, constructs, hypotheses, sample and provenance. Separate source-supported facts from synthesis and proposed methods. For reviews record author, year, DOI, study design, limitations and source location; verify bibliographic metadata. For quantitative work check sample size, missingness, assumptions, effect sizes, confidence intervals and multiple comparisons. Never invent p-values, ICC or results. Respect the project-specific four dimensions (aesthetics, completion, function, creativity) and do not reintroduce removed total-score comparisons. Generate audit trail and identify missing evidence before finalizing.

# Deliverable checklist
- Record inputs and assumptions.
- Produce a draft and inspect it against the user brief.
- Report tests actually run, unresolved risks and next actions.
- Never claim installation, deployment, validation or access that did not occur.
