# Workflow

Start with garment category, intended wearer, dimensions and reference images. Distinguish concept rendering from manufacturable specification. Map each garment into components, seams, closures, grainlines, ease, material behavior and construction order. For technical flats output front/back and isolated garments, no invented invisible details without marking assumptions. For patternmaking distinguish dart manipulation, added fullness and contouring; request body measurements and ease before production DXF. Verify seam matching, notches, allowances and export compatibility. For CLO3D inspect fabric physical properties, fit tension and collision. Gate: anatomical plausibility, constructibility, editable layers, material realism. Cite technical sources and state what was not verified.

# Deliverable checklist
- Record inputs and assumptions.
- Produce a draft and inspect it against the user brief.
- Report tests actually run, unresolved risks and next actions.
- Never claim installation, deployment, validation or access that did not occur.
