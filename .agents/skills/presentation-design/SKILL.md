# Workflow

Establish audience, 1-sentence thesis, duration and slide format. Outline narrative before styling; one dominant message per slide. Build type hierarchy, restrained grid, deliberate negative space and consistent image treatment. Academic charts must preserve denominators, units, scales and statistical uncertainty; avoid decorative distortion and misleading truncated axes. Distinguish source data from illustration. Export editable PPTX and preview rendered slides; inspect overflow, contrast, missing fonts and speaker pacing. Do not fabricate citations or statistics.

# Deliverable checklist
- Record inputs and assumptions.
- Produce a draft and inspect it against the user brief.
- Report tests actually run, unresolved risks and next actions.
- Never claim installation, deployment, validation or access that did not occur.
